Lesson 03

🔎 Searching with ES|QL²

Basics · Real-world Queries · AI · Parsing  ·  35 min

Lesson 03 — ES|QL Building Blocks

A pipeline query language for search, analytics, and transformation — all in one place.

Part 1 — Getting Started

  • Discover → Try ES|QL button
  • FROM logs-* | LIMIT 1000
  • Help → Recommended queries: Identify patterns, time buckets, STATS BY
  • STATS count = COUNT(*) BY host.ip, event.type

Part 2 — How Long Are Processes Running?

FROM logs-*
| WHERE event.type == "start"
    OR event.type == "end"
| STATS start=MIN(@timestamp),
        stop=MAX(@timestamp)
    BY host.ip, process.name
| EVAL duration =
    (TO_LONG(stop)-TO_LONG(start))/1000
| KEEP host.ip, process.name,
       start, stop, duration
| SORT duration DESC
| WHERE duration >= 10

Lesson 03 — Joinless Join & Alerts

Part 3 — The "Joinless Join"

  • Use CASE on event.module to classify rows across all indices: Proxy, Netflow, Email, Threat-Intel, Windows
  • Then STATS with WHERE clauses to find IPs that had both allowed proxy traffic and sanctioned-country NetFlow connections
  • Click Alerts → Create search threshold rule → add to Cases
  • Alert name: Suspicious Network Traffic

Parts 4–5 — AI & Parsing

  • AI Assistant: ask it to write a geo-distance query → one-click Visualize this query
  • Scheduled reports: Export → Schedule export any ES|QL result
  • DISSECT: delimited pattern extraction (no regex)
  • GROK: regex-based field extraction
  • String functions: CONCAT, SPLIT, TRIM, TO_LOWER…
  • Date functions: DATE_TRUNC, DATE_FORMAT, TO_DATETIME

💡 Best practice: Always use a Saved Search as the data source for an ML job — it scopes data precisely and makes jobs reproducible.

Lesson 04 — Three ML Jobs to Build

1 — DNS Tunneling

  • Saved search: network_traffic.dns where etld_plus_one exists
  • Detector: high_info_content on dns.question.name
  • Over field: network_traffic.dns.question.etld_plus_one
  • Influencers: destination.ip, host.name, etld_plus_one
  • Job ID: dns-tunneling · Alert → Cases

2 — Population Analysis

  • Data: Kibana Sample eCommerce
  • Job type: Population
  • Population field: customer_full_name.keyword
  • Metric: sum(taxful_total_price)
  • Job ID: unusual_large_orders
  • Find Wagdi Shaw — $2,250 vs avg $62.44 🚩

3 — Lens → ML Job

  • Kibana Sample Logs → Lens bar by response.keyword
  • Normalize per hour, last 7 days
  • Save to new dashboard
  • Panel 3-dot menu → Detect anomalies
  • Job: response_code_anomalies
  • View results in Anomaly Explorer

Lesson 04 — Calendars & Cross-Job Analysis

🗓 Scheduled Exclusions

  • Search Anomaly Detection Settings
  • Two calendar types: with/without Daylight Savings Time
  • Create calendar: planned_maintenance
  • Assign to one or more jobs
  • Add a New event for future maintenance window
  • Import .ics files for bulk scheduled events

🔭 Anomaly Explorer — All Jobs

  • Open all 4 jobs simultaneously
  • View by: network_traffic.dns.question.etld_plus_one
  • Red tiles = anomalous buckets → click to drill down
  • Jump directly to Discover: gear icon → View in Discover
  • Pre-filtered view for immediate investigation
